New: iMessage, through a Mac you keep on: install BlueBubbles Server on it, then connect it in Settings → Accounts with its address and password.
New: With BlueBubbles' Private API on that Mac, iMessage also has replies, captions on files, tapbacks, editing, unsending, typing and read receipts.
New: A server that runs every network starts an iMessage bridge host after it updates. It connects only to the Macs members add, never to the server's own services.
