Why Trioditis

Sealed by default

Messages are encrypted to each person's own keys before they're stored. Whoever runs the server can back it up and keep it running without being able to read anyone's history.

Your server, your data

The bridges and message storage run on hardware you control. Nothing in the path between you and your networks depends on someone else's cloud.

Honest delivery

No lost messages and no duplicates. When a send's outcome is uncertain, Trioditis tells you instead of quietly trying again.

One server, many people

Host it like Vaultwarden: invite your household or friends. Everyone has their own account and connects their own networks.

Run your own

Any Linux machine, VM or VPS with Docker Engine 28 or later, on x86_64 or arm64.

git clone --branch dev https://github.com/NotAKerbal/trioditis.git
cd trioditis
deploy/install/install.sh

The installer prints a one-time link to create the admin account. The same command upgrades it later. Full guide
