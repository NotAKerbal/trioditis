Why Trioditis

Sealed by default

Your stored inbox is encrypted to keys only your devices hold, so its backups and database dumps are unreadable, even to whoever runs the server. The exceptions: messages pass through the server's bridges in the clear on their way in and out, and a chat you give an agent read access to becomes readable by the server on that agent's behalf. How it works

Your server, your data

The bridges and message storage run on hardware you control. Nothing in the path between you and your networks depends on someone else's cloud.

Honest delivery

When Trioditis can't tell whether a network accepted a message, it says so and lets you decide whether to send it again, instead of quietly resending it and risking a duplicate.

One server, many people

Host it like Vaultwarden: invite your household or friends. Everyone has their own account and connects their own networks.

Desktop app

Your server in its own window, with notifications and an unread badge. For macOS, Windows and Linux.

Run your own

Any Linux machine, VM or VPS, on x86_64 or arm64, with Docker Engine 28 or later and its Compose plugin, Git, and 8 GiB free where Docker keeps its data. 

git clone --branch dev https://github.com/NotAKerbal/trioditis.git
cd trioditis
deploy/install/install.sh

The installer prints a one-time link to create the admin account. Set up HTTPS before you open it from another device. To upgrade, update from Settings → Admin → Updates or run git pull and the installer again. Full guide
