## Brand assets

All canonical brand files live in `assets/brand/`:

| File                                     | Description                                             | Usage                                         |
| ---------------------------------------- | ------------------------------------------------------- | --------------------------------------------- |
| `assets/brand/icon.svg`                  | Transit-junction mark on the `#0284c7` tile             | App icon, favicon, avatars, square placements |
| `assets/brand/icon-mono.svg`             | Single-color tile (`currentColor`) with routes cut out  | System tray, notifications, monochrome print  |
| `assets/brand/wordmark.svg`, `-dark.svg` | Outlined "Trioditis" in DM Sans Bold with accent i-dots | Standalone name lockups                       |
| `assets/brand/lockup.svg`, `-dark.svg`   | Icon and wordmark paired together                       | Site headers, README, documentation           |
| `assets/brand/social-card.png` (`.svg`)  | 1200 × 630 lockup and tagline on ink                    | Open Graph & link previews                    |
| `assets/brand/png/icon-*.png`            | Raster icons from 16 px to 1024 px                      | Installers, Electron, stores, PWA manifests   |
| `assets/brand/favicon.ico`               | Multi-size ICO (16, 32, 48 px)                          | Legacy browser favicon fallback               |
| `@trioditis/ui/wordmark`                 | React inline SVG component following theme tokens       | Inside the Trioditis web & desktop apps       |

The `-dark` variants are for dark surfaces. The square icon tile stays identical across light and dark themes.

## The wordmark

The name is set in **DM Sans Bold** at `-0.01em` tracking, matching the app. **"Trioditis" has three `i`'s, and all three dots are set in the brand accent color**—one for each road—while the letterforms stay ink.

Never retype the wordmark in a live font when placing a logo; always use the generated SVG lockups/wordmarks or `@trioditis/ui/wordmark` so the split accent dots stay exact. In lockups, the wordmark is 60% of the icon height with a 30% gap.

## Color palette

Brand colors match `packages/ui/src/styles/tokens.css`:

| Role            | Light     | Dark      |
| --------------- | --------- | --------- |
| **Accent**      | `#0284c7` | `#38bdf8` |
| **Ink**         | `#0f172a` | `#e9ebf0` |
| **Icon routes** | `#ffffff` | `#ffffff` |

## Usage rules

- Leave clear space around the icon of at least **¼ of its width**.
- Do not recolor the blue tile, rotate the mark, or alter the route geometry (use `icon-mono.svg` for single-color contexts).
- Do not enclose the mark inside another container shape or add drop shadows, outlines, or gradients.
- Do not detach the routes from the rounded tile—the edges are what make it read as a cropped transit map.

## Regenerating assets

Every asset is generated deterministically from `packages/brand/generate.mjs`. After modifying geometry or colors, regenerate and commit all outputs together:

```sh
pnpm --filter @trioditis/brand generate
```

This updates `assets/brand/`, `apps/desktop/public/`, `apps/desktop/electron/`, the installed app's icons in `apps/desktop/build/` (the whole tile for Windows and Linux, and a Mac icon on Apple's grid with a shadow), `apps/site/`, `apps/docs/`, and `packages/ui/src/components/wordmark.tsx` in one pass.
