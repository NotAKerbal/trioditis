# Documentation site

The Astro Starlight documentation site at [docs.trioditis.app](https://docs.trioditis.app).

Run locally from the repository root:

```sh
pnpm docs:dev
pnpm docs:build
```

It deploys as its own Vercel project (`trioditis-docs` in `notakerbals-projects`) with **Root
Directory** set to `apps/docs` and production branch `dev`. `apps/docs/vercel.json` configures the
build, security headers, and git-diff ignore check so unrelated commits skip redeploys.

Brand assets (`public/icon.svg`, `public/favicon.ico`, `public/apple-touch-icon.png`,
`public/social-card.png`, and `src/assets/*.svg`) are generated by `packages/brand/generate.mjs`:

```sh
pnpm --filter @trioditis/brand generate
```
